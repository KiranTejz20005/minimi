FAQ

Questions, answered.

Still unsure? An engineer replies within a day.

Exposing memory as a tool adds a 1-second round-trip and introduces model weekday arithmetic errors. Resolving dates in code guarantees exact calendar calculation.

Any model you can reach over HTTP, and any framework that runs in TypeScript or Python. The SDK wraps your existing agent, so you don’t rewrite it.

User histories are thousands of turns queried by date. A date index plus in-memory BM25 gives instant sub-5ms lookups with zero vector database operational complexity.

Minimi supports Anthropic Claude (3.5 Sonnet / Haiku), OpenAI GPT models, and OpenAI-compatible endpoints like NVIDIA NIM.

Tavily Search for clean structured content with an SQLite cache layer, plus an automatic keyless fallback runner for unauthenticated deployments.

A deterministic post-generation pass inspects all [n] markers in the response and strips any that do not correspond to an actual retrieved source from this turn.
