How it works

Deterministic in three stages.

Code resolves what code can decide. The model is called only when language is needed.

  1. 01Connect

    $ resolveTemporal("last Tuesday")

    Window: 2026-11-10T00:00:00Z

    BM25 ranking scored

    SQLite past turns retrieved

    Temporal Memory Recall

    Maps "Monday", "3 Nov", or "last Tuesday" to exact past turns with BM25 topic ranking.

  2. 02Route
    Primarylarge412 ms
    Fallbacksmall96 ms
    Ceiling$0.02per run

    Parallel Live Search

    Issues independent searches concurrently, trims excerpts, and prevents duplicate API calls.

  3. 03Observe
    Runs / min8,612

    Citations & Claim Digestion

    Streams answers with real citations, then asynchronously stores structured claims.
